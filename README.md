## Bluetooth Microphone Setup

### Pairing a new Bluetooth microphone

```bash
# Open Bluetooth control
bluetoothctl

# Commands inside bluetoothctl:
power on
agent on
scan on
# → Note the MAC address of your mic (e.g. AA:BB:CC:DD:EE:FF)
pair AA:BB:CC:DD:EE:FF
connect AA:BB:CC:DD:EE:FF
trust AA:BB:CC:DD:EE:FF    # auto-reconnect on boot
exit
```

### Verify PipeWire sees the device

```bash
# List all audio source nodes
pw-dump | python3 -c "
import json, sys
nodes = json.load(sys.stdin)
for n in nodes:
    if n.get('type') == 'PipeWire:Interface:Node':
        props = n.get('info',{}).get('props',{})
        if 'Source' in props.get('media.class',''):
            print(n['id'], props.get('node.nick','?'), props.get('api.bluez5.address',''))
"
```

### Test a single device capture

```bash
# Record 5 seconds from device ID 47 (replace with your ID)
pw-record --target 47 --rate 16000 --channels 1 --format s16 test.raw
# Play back:
aplay -f S16_LE -r 16000 -c 1 test.raw
```

## Whisper Model Selection

| Model     | VRAM  | Speed  | Accuracy | Notes                        |
|-----------|-------|--------|----------|------------------------------|
| large-v3  | 10 GB | ~1.5s  | Best     | Recommended for Quadro 5000  |
| medium    | 5 GB  | ~0.8s  | Good     | Fallback if VRAM is tight    |
| small     | 2 GB  | ~0.4s  | Fair     | CPU viable                   |
| base      | 1 GB  | ~0.2s  | Moderate | Testing only                 |

Change model in `app.py`:
```python
WHISPER_MODEL = "large-v3"    # or "medium", "small", "base"
```

## REST API Reference

| Method | Endpoint                    | Description                    |
|--------|-----------------------------|--------------------------------|
| GET    | `/`                         | Serve the UI                   |
| GET    | `/api/speakers`             | List active speakers           |
| GET    | `/api/devices`              | List all discovered devices    |
| GET    | `/api/history/{device_id}`  | Get transcript history         |
| POST   | `/api/rename`               | Rename a speaker               |
| POST   | `/api/add_speaker`          | Activate an additional device  |
| POST   | `/api/remove_speaker/{id}`  | Deactivate a speaker           |
| DELETE | `/api/history/{device_id}`  | Clear history for a speaker    |

### WebSocket events (`ws://host/ws`)

**Server → Client:**
```json
{ "type": "init",            "data": { "speakers": [...], "history": {...} } }
{ "type": "transcript",      "data": { "device_id": 1, "speaker_name": "Mom", "text": "...", "language": "es", "confidence": 0.95, "timestamp": 1234567890 } }

```

**Client → Server:**
```json

{ "type": "clear_speaker", "device_id": 1 }
```

## Improving VAD Accuracy

The default energy-based VAD works well in quiet environments. For noisy settings, replace with **Silero VAD**:

```python
# In vad_transcriber.py, replace the energy check:
# 1. pip install torch torchaudio
# 2. Load Silero:
import torch
silero_model, utils = torch.hub.load(
    repo_or_dir='snakers4/silero-vad',
    model='silero_vad',
)
get_speech_timestamps = utils[0]

# 3. In process_audio_chunk():
speech_prob = silero_model(torch.from_numpy(pcm), 16000).item()
is_speech = speech_prob > 0.5   # Replace energy threshold check
```

## Troubleshooting

**No devices found:**
```bash
systemctl --user status pipewire
systemctl --user restart pipewire wireplumber
```

**Transcription is slow:**
- Ensure `nvidia-smi` shows the Quadro 5000
- Check `compute_type = "float16"` (not `"float32"`)
- Try `model_size = "medium"` for ~2× speedup

**Audio cuts out:**
- Check BT signal strength: `bluetoothctl info AA:BB:CC:DD:EE:FF`
- Increase chunk size in `audio_manager.py`: `CHUNK_DURATION_MS = 60`

**UI not updating:**
- Check browser console for WebSocket errors
- Ensure `uvicorn` is running: `curl http://localhost:8000/api/speakers`
